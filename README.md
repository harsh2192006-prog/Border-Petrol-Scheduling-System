# Border Petrol Scheduling System

## Project Description

The Border Petrol Scheduling System is a web-based application designed to manage petrol stations, vehicles, fuel requests, fuel availability, and petrol scheduling in an organized way.

## Main Modules

1. User Authentication
2. Petrol Station Management
3. Vehicle Management
4. Fuel Request Management
5. Petrol Scheduling
6. Fuel Management
7. Fuel Transactions
8. Reports
9. Testing

## Project Objective

The main objective of this project is to provide a computerized system for managing petrol scheduling, fuel requests, vehicle information, station information, and fuel transactions.
